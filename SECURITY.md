# Security Policy

Please do not disclose credentials, unsafe robot-control behavior, or other
security-sensitive issues in a public issue.

Report vulnerabilities privately through GitHub's **Security advisories**
page for this repository. Include affected versions, reproduction steps, and
the impact when possible. If private advisories are unavailable, contact the
maintainers using the address published in the package metadata.

Only the latest revision of the default branch is actively maintained. Never
include API keys, access tokens, private datasets, or personally identifying
recordings in a report.
